Gateway & Web Search Connector Setup

AgentCore's Gateway is the piece that routes an agent's tool calls through managed connectors — it's what turns "Amazon runs a web index" into "your code can call a tool named WebSearch." This page is the plumbing every tutorial skips: without a Gateway and a Web Search target provisioned here, every other page on this site has nothing to talk to.

Two separate IAM sides, and why both exist: outbound — the Gateway's own service role needs bedrock-agentcore:InvokeWebSearch on the managed web-search tool, so the Gateway itself can reach AWS's index. inbound — whoever calls the Gateway (this app) needs bedrock-agentcore:InvokeGateway on the Gateway ARN, so AWS knows you're allowed to use it. With authorizerType=AWS_IAM that's a plain SigV4-signed call — no Cognito/OAuth setup required, which is the difference between a five-minute personal project and a half-day identity-provider integration.
