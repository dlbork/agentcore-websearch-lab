Query Ledger ($7 / 1,000 Queries)

Every call to Web Search anywhere on this site — raw search, compare, parameter sweep, agent loop — is logged here and costs real money. This page is the running total, so "how much did I spend learning this" has an actual answer instead of a shrug.

What: billed queries vs. cache hits, and the dollar total. Why you should care: at $7 per 1,000 queries ($0.007 each), casual exploration is genuinely cheap — but it's not free, and a runaway loop or an unauthenticated public endpoint could rack up a real bill without anyone noticing. Repeat queries (same tool + query + params) are served from the on-disk cache and don't re-bill.
